# Global Smartphone Database 2025

Metadata seed source: [Kaggle dataset](https://www.kaggle.com/datasets/rajibdab/global-smartphone-database-2025), published under Apache-2.0 (verified 2026-08-23).

Only `brand`, `model`, `device_type`, and a parsed release year are imported. Image URLs, detailed specifications, prices, and source-site text are excluded. Imported records are `draft` candidates and require a human review plus a final approved asset before publication.
